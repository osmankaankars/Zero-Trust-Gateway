# Security policy

## Scope

Security reports are welcome for the current `0.2.x` line. This repository is
an isolated learning lab, not a production access proxy. Please do not test it
against systems you do not own or have explicit permission to assess.

## Reporting

Use GitHub's **Report a vulnerability** flow in the repository Security tab.
Please include the affected version, a minimal reproduction, impact, and any
suggested mitigation. Do not place credentials, private keys, personal data, or
third-party system details in a public issue.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier PoC revisions | No |

The maintainer will acknowledge a complete report when practicable. No response
time or bounty is promised.
